# Current state

Resident Expert Framework v1.0.0 is initialized as a public repository.

The repository contains the canonical constitution, generic expert profile, consultation protocol, four framework skills, Context Capsule v1.3 metadata and semantic state, request/report schemas, behavioral eval cases, a lightweight validator, and a GitHub custom-agent adapter.

The framework is intentionally not domain-specialized yet. Its next substantive use is to create the first concrete narrow expert by defining a domain profile, adding domain skills/references, and extending evals.
