# Evidence-first analysis

Use for substantive expert judgments.

For every material conclusion:

- identify the evidence that supports it;
- distinguish repository fact from interpretation;
- identify relevant conflicting evidence;
- state uncertainty when evidence is incomplete;
- avoid substituting general best practice for facts about the target;
- request or retrieve the smallest additional evidence needed;
- prefer falsifiable claims and concrete failure modes over vague quality labels.

The output should be audit-friendly without exposing private chain-of-thought.
