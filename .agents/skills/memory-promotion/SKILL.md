# Memory promotion

Use only when a consultation or maintenance task reveals a potentially reusable lesson.

Promote a lesson only if it is:

- cross-project rather than specific to one target;
- evidence-backed;
- likely to change future expert behavior materially;
- compatible with the expert's specialization;
- safe to persist without secrets or unnecessary personal data.

Do not promote:

- ordinary target facts;
- temporary runtime state;
- one-off filenames, IDs, credentials, or private data;
- unverified hypotheses;
- the user's project-specific decisions unless they define the expert itself.

When promoted, record why the lesson is reusable and where it is stored.
