# Expert consultation

Use when the user asks for the expert's opinion, audit, critique, review, or recommendation about a target project.

Required behavior:

1. Restate the precise question internally as the analysis scope.
2. Recover target context if the answer depends on project state.
3. Load only domain skills needed for that question.
4. Analyze evidence independently from the target project's prior conclusions.
5. Report facts, analysis, uncertainties, and recommendations distinctly.
6. Do not modify the target project.
7. Do not store ordinary consultation content as expert memory.
